Entregue o conjunto e reconheça sua autonomia

Você consegue organizar três peças e explicar as decisões do projeto.

O projeto não termina quando a imagem fica bonita. Quem recebe precisa entender quais arquivos usar e o que foi feito.

Em 1 minuto

  1. Separe finais e materiais de trabalho.
  2. Inclua uma nota com uso e limitações.
  3. Mostre o que consegue decidir sem copiar a aula.

1Monte o pacote de entrega

Um pacote organizado contém finais, referências autorizadas, prompts, configurações e instruções curtas para reutilizar.

Mantenha arquivos de teste separados das versões aprovadas.

Outra pessoa — ou você daqui a um mês — precisa encontrar a imagem correta sem abrir dezenas de arquivos.

Organização também permite revisar só a peça necessária.

Joana prepara uma pasta com as três imagens finais. Ela mantém as tentativas em outra pasta para não confundir quem recebe.

2Revise o que você consegue fazer

Concluir uma leitura e dominar uma habilidade são coisas diferentes.

O projeto deve mostrar que você consegue descrever uma cena, testar uma variável, reconhecer um erro e corrigir sem perder a intenção.

A revisão final transforma um exercício terminado em próximos passos concretos.

Dúvidas remanescentes indicam qual módulo revisitar.

Mauro lê a nota de entrega e sabe qual imagem vai para catálogo e qual mostra o detalhe. Ele também sabe o que ainda exige revisão.

3Confira a decisão pelo uso

Concluir a leitura não comprova domínio. A evidência é conseguir justificar uma escolha, corrigir um defeito e entregar arquivos utilizáveis.

Mauro usa a observação abaixo para decidir: nota → uso de cada peça e pendências reais.

Teste-se

O projeto contém duas peças prontas e uma só planejada. Como entregar?

Se travou aqui, é normalAinda não gerou as três peças? Registre o plano como pendente e execute uma por sessão. Não marque uma produção inexistente como concluída.

Revise o que você consegue fazer

Experimente com calma

Sem consultar o texto, explique uma imagem em cinco decisões. Depois faça um novo prompt para outro objeto usando o mesmo raciocínio. Liste uma habilidade que ficou clara e uma que precisa de outra prática.

O que observar

Não marque domínio apenas porque a imagem ficou bonita. Verifique se você consegue explicar e repetir o processo com um novo exemplo.

Pedido completo para experimentar
